#### Unreleased — 0.1.0

Initial scope, built and verified against a DocuSign demo sandbox but not yet published to npm.

- Envelope resource with three operations: Create From Template, Get Status, Download Document
- JWT Grant credential (`DocuSignApi`) — RS256 assertion signed with Node's built-in `node:crypto`, exchanged for an access token and cached via an expirable hidden field, with `consent_required` surfaced as an actionable message containing the consent URL
- Per-account API host discovery via `/oauth/userinfo` in a `resolveAccountBaseUrl` preSend, since n8n resolves URL expressions before credentials can influence them
- Binary output for downloaded documents (`arraybuffer` + `binaryData` postReceive)
- Unit tests for the request-shaping helpers and structural tests over the node description
